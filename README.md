# Fala – minimalistyczny launcher na Androida

Launcher w stylu Niagara: duży zegar, lista ulubionych, alfabetyczna lista aplikacji i pasek liter z efektem fali.

## Funkcje
- Duży zegar i data (dotknij zegara → alarmy, dotknij daty → kalendarz)
- Ulubione aplikacje na górze (przytrzymaj aplikację → dodaj / usuń / przesuń)
- Pasek liter po prawej z animacją fali – przesuń palcem, aby przewinąć do litery
- Wyszukiwarka (przycisk lupy); Enter uruchamia pierwszy wynik albo szuka w internecie
- Przeciągnięcie w dół na górze ekranu otwiera powiadomienia
- Przytrzymaj zegar → ustawienia (ikony, tapeta, domyślny launcher)
- Obsługa profilu służbowego, przezroczystość na tapecie

## Instalacja
1. Wejdź w zakładkę **Releases** tego repozytorium na telefonie i pobierz `Fala-Launcher.apk`.
2. Zainstaluj (zezwól na instalację z nieznanych źródeł).
3. Naciśnij przycisk Home i wybierz **Fala** → „Zawsze”.

APK buduje się automatycznie przez GitHub Actions po każdym pushu na `main`.
